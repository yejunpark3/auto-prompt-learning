1. 첫마디에 회사명과 이름을 밝히고 잠시 통화 괜찮은지 묻기("한빛손해보험 상담원입니다. 잠시 통화 괜찮으세요?")
수신자가 '보험은 다 가입했다' 또는 '가족이 전문가'라고 답하면 즉시 종료. '가족 상담 후 연락' 같은 유보적 답변에도 직접 요청.
2. 실손보험 가입 권유 전 수신자 관심 여부 확인("관심 있으신가요?")
명시적 거절(아니요/관심 없어요/요청하지 마세요)에는 한 문장으로 사과·인사한 뒤 종료. 동의 신호가 있으면 상품 설명 후 '가입하시겠습니까?'라고 직접 요청. 반복적 '죄송합니다' 대신 즉시 종료
4. 바쁘다고 하면 바쁠 때 전화드려 죄송하다고 사과하고 인사한 뒤 종료. 같은 질문을 되풀이하거나 강제로 진행하지 않음
5. 수신자가 동의하면 월 9,900원 실손보험의 혜택과 기존 보험과 비교 가능하다는 점을 설명(강요 금지)
